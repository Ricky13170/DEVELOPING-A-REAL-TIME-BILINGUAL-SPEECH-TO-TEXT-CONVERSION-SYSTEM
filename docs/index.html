Features

Built for Real-World Use

Every component is designed to handle the chaos of live speech

⚡

Latency by Design

Single-flight decoding, short segment buffering, and beam size 1 reduce duplicate inference. Current results are re-benchmarked per device.

🛡️

Confidence-Aware Output

Low-confidence or silent segments are rejected without loading a second correction model or repeating expensive ASR passes.

🎯

Context Priming

Local domain templates prime factory, maintenance, logistics, electrical, construction, and safety vocabulary. Cloud expansion is optional.

🖥️

Stable Display

Local Agreement algorithm prevents flickering in partial transcriptions — smooth, readable output.

🌊

Adaptive Energy VAD

A lightweight CPU gate adapts to the background level without loading a second neural model for every session.

📡

Local WebRTC Streaming

Direct WebRTC media is attempted on localhost/LAN; a WebSocket path remains the deterministic fallback.
